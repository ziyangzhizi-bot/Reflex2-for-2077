# Reflex2 — v0.9.0-rc1 发布说明 / Mod 页面文案

> 可直接作为 mod 发布页正文(Nexus / GitHub Release 等)。技术细节见 `README_CN.md`、`CHANGELOG.md`、
> `THIRD_PARTY_NOTICES.md`。

## 这是什么

用 **NVIDIA 驱动自带的 latewarp 内核**(NGX feature 15,`nvngx_latewarp.dll`)给
**Cyberpunk 2077** 的画面做**可见的一帧位移 / 扭曲** —— 位移由 NVIDIA 内核完成,
本 mod **不含任何自写的重投影、运动矢量或深度数学**。

配合 ReShade 使用,所有开关都在 **ReShade 面板里**(中文标签),**不需要热键、不需要手改配置文件**。

## 效果与体验

* 快速转头、转身、急停时能看到清晰的"帧扭曲 / 拖影错位";
* 提供 **UI 保护阈值**、**深度截断**(武器/手)、**深度反向**、**遮罩可视化**等滑块;
* 面板内提供 **只读状态**(是否在工作、当前分辨率、交换链代号、内核已扭曲帧数)。

## 需要什么

| 项目 | 要求 |
|---|---|
| 游戏 | Cyberpunk 2077(Steam / GOG / Epic 均可) |
| ReShade | **6.8.0(实测)**、64 位、**带 addon 支持** |
| 显卡 | **NVIDIA RTX 40 系或更新**(依赖驱动的 `nvngx_latewarp.dll`) |
| 驱动 | 实测 **617.14**(RTX 4060 Laptop);开发期间更新过一次驱动,mod 仍正常 |
| 游戏内设置 | 建议开 DLSS 超分;本 mod 与帧生成无关,不依赖它 |

## 安装

1. 解压发布包,在解压目录里打开 PowerShell:
   ```powershell
   .\install.ps1 -SelfCheck   # 先看环境(不动任何文件)
   .\install.ps1              # 正式安装(建议先退出游戏)
   ```
2. 安装脚本会自动:**备份被覆盖的文件**(到 `bin\x64\_fwbackup_<时间戳>\`)、复制插件与着色器、
   写入默认开关,并在结束时**校验哈希**。
3. 卸载:`.\install.ps1 -Uninstall`(只会删本 mod 的文件)。

## 使用方法

1. 启动游戏,按 ReShade 面板热键(默认 `Home`)打开面板;
2. 勾上 **`routea_ui_panel.fx`** —— 6 个中文滑块 + 5 个只读状态都在这里;
3. 想临时关掉:去掉 `routea_switch.fx` 的 **"Reflex2: 帧扭曲"** 勾选(面板勾选现在等于**完全惰性**,
   不再只是"不扭"而已)。

## ⚠️ 最重要的一条:改分辨率不要直接回存档

* **最稳**:进游戏之前就把分辨率设好(桌面 / 启动器 / NVIDIA 面板),之后全程不需要切换;
* **游戏内改**:设置里改分辨率 → **先回主菜单** → 再从主菜单读档进游戏。
  改完后本局扭曲会**自动停用**(保护措施),**重启游戏**即恢复;面板状态会显示 `2 已降级`;
* **不要**:改完分辨率**直接点"返回存档"** —— 会在数秒内闪退。该问题出现在游戏/DXGI 侧,
  插件在换链后已完全静默仍会复现,因此以"避免这个操作"的形式发布。

## 已知限制

* 上述"改分辨率 → 直接回存档"路径;
* HUD **平坦区域**(血条填充、面板底色)仍可能被扭;轮廓与文字受保护;
* 位移是**一帧**位移(使用引擎发布的一帧 delta),观感上有一帧延迟;
* 与帧生成(DLSS-G)无关。
